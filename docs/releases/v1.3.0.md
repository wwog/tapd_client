# TAPD Client v1.3.0

发布日期：2026-11-16

## 新增

- 本地项目与事项：项目页 / 侧栏右键可创建只存在本机的项目（不需要 TAPD），事项有「待处理 / 处理中 / 已完成」三个状态；关联 Agent 任务成功时自动进入已完成，也可手动标记 / 重新打开。事项可一键交给 Agent，复用现有队列、Worktree、审核与合并，导出 `quest.json` 而不是 `bug.json`，不写回 TAPD。
- 本地项目规则：项目创建 / 编辑时可填写规则，入队时随 `quest.json` 导出并追加到本地修复、提交与合并提示词；TAPD 项目提示词不受影响。
- 移动端「事项」tab：可浏览桌面目录创建本地项目并填写规则，编辑项目名称 / 规则，新增 / 编辑 / 删除事项，在三种状态之间移动，并从手机发起 Agent 任务。
- 移动端文件 / 终端：只列出配置了文件夹的 TAPD 项目，并加入本地项目；文件页新增「根目录」来源，可从 `/` 只读浏览整个文件系统（写接口对根目录返回 403），终端新建仍保留「家目录」。
- Agent 任务新增来源类型：`sourceKind = tapd_bug | local_work_item`；本地任务的提示词、提交 / 合并文案与 `local/` 分支前缀均与 TAPD 缺陷分开，Agent 页与胶囊不再显示「打开缺陷」。
- 底部终端面板：内容区头部终端按钮或 `⌘J` 打开，多标签各自一个真实 shell（默认在当前项目目录启动）；面板跨页面常驻，切换缺陷 / Agent / 设置不影响正在运行的终端。会话由后端持有，收起面板只关闭视图，重新打开回放最近的输出；标签可关闭、进程退出后可原地重新启动。
- 移动端伴侣新增「终端」页：列出桌面端正在运行 / 已退出的会话，点进全屏终端即可远程操作（类似 SSH），带 Esc / Tab / Ctrl / 方向键工具条；WebSocket 实时收发，断线自动重连并回放。
- 移动端终端补齐：新建会话时可选「家目录」或某个项目（由桌面解析项目配置的仓库目录）；行输入支持本机命令历史、←/→ 移动光标、一键遮蔽输入、键盘弹起时收起按键条、模式与草稿记忆；会话被关闭/桌面重启时显示「终端已结束」而不是空屏重连。
- 桌面终端标题跟随 shell 的 OSC 0/2，`cd` 后的 OSC 7 同步 cwd；Tab 与手机列表不再固定为启动目录名。
- 全产品中英双语：桌面端界面、Rust 后端提示（缺陷写回、通知、伴侣、更新诊断）、Agent 运行时描述与生命周期文案、MCP 工具文档、移动端伴侣均可切换语言。设置 → 外观 → 语言可选「跟随系统 / 中文 / English」，默认跟随系统语言并写入 `config.json`，切换即时生效且保留当前页面。
- 移动端伴侣设置页新增语言切换（本机偏好，不跟随桌面端）。
- 日期与时间格式随界面语言切换（`zh-CN` / `en-US`）。
- 工作区（Workbench）：主内容、右侧详情、底部终端统一成分割树 + 标签组，标签可在任意组之间拖动、拖到组边缘四向分裂；分割条与交叉点统一（交叉点一次同时调整宽/高），双击分割条复位；布局按项目配置持久化，重启恢复。标签移动不会重建终端、详情或文件视图，回放与滚动位置保留。
- 资源管理器与文件查看：项目行右键「浏览文件」、行内文件图标或再次点击当前项目，即可在右侧打开资源管理器；支持懒加载目录、隐藏文件开关、键盘导航，点击代码 / 图片 / Markdown / 音视频 / 二进制文件在标签中预览（代码行号与语法高亮、图片适应/原始尺寸、Markdown 预览），并可复制路径或用系统应用打开。文件访问限制在项目配置的本地文件夹内，仅接受相对路径并拒绝符号链接逃逸。
- 移动端伴侣新增「文件」页：项目切换、面包屑目录浏览、隐藏文件开关，以及文本 / Markdown / 图片 / 音视频预览；内容按只读方式渲染，不执行文件中的 HTML。
- 文件编辑（桌面）：文本 / 代码面板改用 Monaco，可直接修改并用 `⌘S` 保存；标签与文件头显示未保存圆点，关闭时确认「放弃并关闭 / 继续编辑」，文件被外部修改时提示重新加载或覆盖。Monaco 按需加载，不影响启动。
- 文件编辑（移动端）：设置 → 项目文件里开启「允许编辑项目文件」后（默认关闭），文件页可用等宽编辑器修改并保存；保存同样做 mtime 冲突校验，手机上默认仅预览。
- 多设备配对与设备管理权限：第一台配对设备默认可在手机端管理其他设备，电脑端设备列表可开关任意设备（包括第一台）的管理权限；手机端管理员可开关权限、解除其他设备，非管理员不显示管理入口。配对弹窗新增多设备说明。
- 任务变更记录：运行中、待审核、待合并与历史都能看本次改动的文件列表、逐文件与整体 `+A −D`，点开看单文件 diff；任务头部直接显示代码量。实时更新来自 Agent 会话 hook 的编辑类工具事件（去抖 800ms、单飞、后台线程跑 git），不做轮询。
- Worktree 任务在运行 / 待审核 / 待合并阶段可一键「打开 worktree」，与「打开项目」共用编辑器选择；成功后目录清理，入口随任务结束隐藏。
- 合并结果记录落地 commit：合并卡与历史显示可复制的短 hash，手动核验同样记录；单任务模式显示主仓库提交。
- 移动端伴侣任务页新增「变更」区：文件列表、逐文件行数、底部弹层看 diff；审核 / 合并卡与历史显示代码量与合并 hash。

## 修改

- 文件查看器改用与项目头部一致的「打开 ⌄」分体按钮：左半部分按上次选择的应用打开，下拉里选应用会立即用它打开，并按图片 / 视频 / 其它文件分别记住选择；二进制与超大文件的空态也复用同一按钮，不再用单独的外链图标。
- 本地项目数据写入独立的 `<数据目录>/local.sqlite3`：TAPD 退出登录与 `Cache::clear()` 不再影响它；「清理缓存」显式保留该库及 WAL 旁文件。schema v2 为 `local_projects` 增加 `rule`，已有 v1 库启动时执行一次 `ALTER TABLE` 迁移。
- 项目侧栏与项目页同时承载 TAPD 项目与本地项目；侧栏高亮跟随当前页，切回缺陷列表时 TAPD 成员目录正常加载。文件浏览与终端对本地项目复用同一目录解析（TAPD 配置优先，其次本地仓库）。
- 本地项目与 TAPD 项目在主视图各开独立标签：从项目列或项目页点开项目就打开（或聚焦）它自己的页面，本地项目标签固定排在最前，标签可关闭、可拖动，同时开着多个项目时互不替换；左侧导航移除「事项」入口，选中本地项目时「缺陷」入口保持高亮，事项统一从项目进入。全局页面（项目 / Agent / 同事 / MCP / 设置 / 账号）共用一个导航标签，切换时替换内容而不是累积，且只在可见时存在：激活任一项目标签会把它收起，再点左侧导航时重新出现，不会在项目标签旁留下「项目」这类固定标签；右侧 / 底部停靠组首次打开时按存储比例从 0 展开（旁边组同步缩放）；没有关闭按钮的标签补齐右侧内边距。
- 本地项目行补上右侧「浏览文件」图标与右键菜单入口，与 TAPD 项目一致。
- 变更与 diff 统一交给新的 `tapd-workspace` 模块：行数、文件状态、二进制与 diff 文本全部由 git 子命令产出；worktree 目录清理后按分支重算，历史仍可回看 diff；单任务与 Worktree 模式共用同一套实现。
- 移动端伴侣配对码不再 10 分钟过期：应用运行期间始终有效；每次配对成功后自动换新码，旧码作废，已配对设备不受影响。弹窗移除「重新生成」按钮。
- 终端入口移到左侧导航栏底部（设置上方），内容区头部不再单独放按钮；移动端终端默认「行输入」：命令在本机编辑、回车一次性发送，打字不再受隧道往返延迟影响（实测 0.8–2s），全屏程序可切「直通」逐键下发；直通与桌面端输入按 30–40ms 封顶合并，逐键不再各走一次阻塞写入。
- 终端安全性：远程终端 WebSocket 改用 60 秒、单次、绑定会话的票据（`terminal_ticket`），长期会话 token 不再出现在 URL 和隧道访问日志；旧 `t=` 仍兼容。
- 终端稳定性：输入队列按 1 MiB 封顶并在超限时明确报错；会话到 8 个上限时先回收已退出会话；回放先清屏并从完整行开始；shell 退出由独立 waiter 上报并在 150ms 内排空尾帧，孙进程持有 PTY 也不会让会话永远显示运行中。
- 移动端终端支持手指上下滑动回看历史输出（xterm 原生触摸只做选区），带短惯性与滚动条拖动；滚动结束不会误触发输入框和键盘。
- 主视图区从静态网格升级为分割树：各区域的位置、顺序与大小由拖动标签 / 分割条决定，不再由打开顺序决定谁占整幅；侧边栏、详情、终端统一分割条外观与拖拽手感，尺寸持久化。
- 媒体资源只下载一次：缺陷导出、界面 / 手机端媒体代理与打开原图共用 `<数据目录>/media-cache/` 里按 URL 寻址的磁盘缓存，重复导出同一缺陷、反复渲染详情或重新打开同一张图都不再回源；代理的 `Range` 请求直接从缓存文件切片（视频仍可拖动进度），缓存超过 2GB 时淘汰最久未修改的条目。
- 文案目录改为「短语义 key + 中英成对条目」：key 按界面模块点分命名（如 `common.save`、`bugs.sortAscending`），中英文写在同一行，缺一侧在评审时即可发现；英文缺失时回退另一语言。新增 `docs/I18N.md` 约定与 `pnpm i18n:check` 覆盖率检查。
- 缺陷列表标题不再弹原生 tooltip：超长标题在单元格内就地横向滚动播放，时长随超出距离缩放，鼠标移开复位。
- 长标题 hover 滚动改为匀速：时长按超出距离线性计算（不再有 2.5s / 6s 上限），结尾不再减速；鼠标移开仍快速复位。缺陷标题与 Agent 任务标题等所有 `ScrollingName` 一致。
- Agent 任务标题统一单行滚动：任务头部、排队 / 审核 / 历史列表与详情都不再用省略号，空间不足时状态与运行时徽标换行、标题保留最小宽度，超长标题悬停就地滚动显示全文。
- 伴侣弹窗改为按内容自适应高度：窗口偏小时内容可滚动、二维码随窗口高度缩放，不再被截断；窗口偏大时底部不再留白。
- 右键菜单重做：缺陷表格、项目侧栏、Agent 历史共用 `ContextMenu`，更宽更高（208px，行高加大，图标与分隔线统一），位置按实测尺寸夹在窗口内；进出场带缩放淡入 / 淡出，复制反馈显示完才收起。
- 弹窗统一开关动画：`Dialog` 的面板与蒙层先播退场再卸载；文件夹选择器、Agent 补充说明底部面板、强制更新弹窗复用同一套动效与关闭生命周期（`useLayerClose`）；`prefers-reduced-motion` 下自动关闭。
- 文件查看由 Prism 高亮换成 Monaco：保留行号、自动换行与主题联动，增加撤销 / 重做、多光标与 `⌘S`；移除 `refractor` 依赖。
- 文件能力从只读扩展为受控写入：`fs_write` 只覆盖已存在的文本文件（上限 2 MiB），同目录临时文件 + rename 保留原权限，按加载时 `mtime` 做冲突检测，`force` 才覆盖。
- 手机文件页的「根目录」继续可用，但不再读取私钥与云凭据（`~/.ssh`、`~/.aws`、`~/.gnupg`、`~/.kube/config`、`~/.docker/config.json` 等）以及本应用自己的配置目录。
- 手机端媒体 / 文件 URL 不再携带长期会话 token，改用每次启动派生的只读凭证；未刷新的旧页面仍兼容。
- 手机首次配对会生成稳定的设备标识，重扫同一台设备保留原来的管理与权限设置。

## 修复

- 启动时左侧项目列表先空着、稍后突兀地弹出来：是否显示取决于 TAPD 项目数、本机隐藏项与本地项目，而这些数据在首帧之后才返回；现在窗口显示前先读取会话、缓存的项目列表与本地项目，首帧就给出正确结果，本地项目数也参与判断。
- 打开右侧详情面板时左侧项目列表先收起、随后又展开：扩窗的 resize 还没落地，侧栏已按当前较窄的窗口自动收起；现在扩窗期间按目标宽度判断，只有屏幕实在放不下时才收起。
- 详情面板展开动画期间缺陷列表工具栏会先折成两行：工具栏不再换行，搜索框只在宽度持续不足 300ms 后才隐藏，动画与扩窗造成的瞬时变窄不会再让搜索闪烁或换行。
- 同一标签组里有多个标签时，只有最后一个标签的视图能接收鼠标：每个面板的全屏挂载层按标签顺序堆叠，最上层的透明层把点击 / 滚动 / 焦点都拦住了；现在非活动面板的挂载层不参与命中测试。
- Markdown 预览的安全漏洞：README / Agent 对话里的原始 HTML 会被直接渲染，`iframe`/`script` 可借用主窗口的 Tauri IPC；现在统一经 `rehype-sanitize` 清洗后再渲染。
- 未保存的预览标签会被下一个文件替换并丢掉草稿；现在有修改的预览标签自动固定，退出登录与关闭窗口也会先确认。
- 保存过程中继续输入的内容会被回包覆盖：桌面与手机都只清除已保存的那一版，后续输入保留为未保存状态。
- 文件冲突检测从秒级改为毫秒级（`mtimeMs`），同一秒内的外部修改不会再被静默覆盖。
- `.git` 目录可通过大小写变体或在仓库内放 `docs -> .git` 符号链接绕过；现在规范化后按组件忽略大小写拒绝。
- 伴侣写文件接口要求 `text` 必填（缺字段不再清空文件），拒绝覆盖二进制或超过 2 MiB 的现有文件，临时文件改用 `create_new`，请求体上限提到 8 MiB。
- 移动端文件预览没有语法高亮：改为 highlight.js（覆盖 Swift / Kotlin / Rust / TypeScript 等常见语言，随预览懒加载），浅色与深色共用桌面同款色板。
- iOS 聚焦输入框会自动放大页面：手机端表单控件统一 16px，编辑代码或搜索时视口不再跳动。
- 主窗口是隐藏创建、首帧后才显示的，工作区布局区的首次测量可能为 0 并导致整个分割树不显示；现在测量为 0 时按帧重试，并在窗口 resize 与页面重新可见时补测。
- 资源管理器单击文件应打开可替换的预览标签、双击才固定；此前单击会固定标签、双击反而变成预览。
- 缺陷列表工具栏在窄容器里会把搜索框挤到第二行：现在按实际内容测量，放不下就隐藏搜索、只留筛选按钮，容器再窄才换行。
- 项目侧栏收起 / 展开时项目名被逐帧挤压重排：列表内容保留最小宽度，由侧栏边缘裁切，文字只在两侧逐渐露出或消失。
- 只有一个面板组（没有其它已打开的面板）时，组头部仍显示「放大」按钮且点了没反应：现在没有可隐藏的组就不显示该按钮，标签右键菜单里的「最大化」一并去掉；已最大化时仍保留「还原」。
- 扫码后没能进入 TAPD（账号未开通、没有项目权限等）时，登录页一直停在「正在建立连接」，网页上的报错看不到：现在识别 TAPD 返回的拒绝页面并给出可操作提示，刷新二维码即可重试。
- 退出登录再换账号登录，会看到上一个账号的项目标签并永远显示骨架屏：现在退出时同步清掉当前项目，项目页不会跨账号残留。
- 合并成功后合并卡与历史看不到合并提交的短 hash：现在自动合并与手动核验都会记录并显示。
- 在「打开 worktree」里改完再点通过，改动不会进入合并：现在审批前总是重新核对工作区状态。
- Agent 任务在崩溃 / 重启后可能被当成仍在运行并重复执行：持久化改为按最新状态写入，恢复不会重跑已完成或已取消的任务。
- 合并校验与合并同时发生时，回执会把任务从「合并中」退回，甚至启动第二个合并：现在只有发起校验时的阶段能接受结果。
- 同一任务在桌面和手机上同时点通过 / 停止会互相打断（储藏掉已重新入队的改动）：现在同一任务的审核操作互斥。
- 有空停靠组（例如关闭了的侧栏组）时，分割条拖不动或往反方向跳：现在按实际渲染的宽度拖动，空组保留自己的比例。
- 关闭终端标签或退出应用时，可能向已被系统复用的进程号发信号：现在进程一回收就不再发信号。
- 伴侣里解除配对或关闭服务后，手机已连接的终端仍然可以读写：现在会立即断开。
- 两台同名手机（例如两台 iPhone）配对会互相顶替，第二台还继承管理权限：现在按设备自己的标识区分，重扫同一台手机仍保留原设备。
- `config.json` 损坏时整份配置被静默重置（MCP 策略被放宽、配对设备丢失）：现在把原文件另存为 `.corrupt-*` 并提示，MCP 写权限降为只读。
- 导出缺陷时会把 TAPD 会话 Cookie 发给正文里的第三方图片地址：现在只对 tapd.cn 域名附带 Cookie。
- 超过 2 MiB 的文本文件截断在多字节字符中间时会被当成「二进制」：现在保留文本预览。
- 图片 / 视频代理先把整个文件读进内存再判断大小，大附件会让内存暴涨：现在边读边限流。
- 视频拖动进度时每次都整文件读一遍：现在只读请求的区间。
- 大量未跟踪文件时变更面板刷新很慢：现在一次 git 完成统计。
- Agent 终端在 TUI 暂时不读输入时会把界面卡住：输入改为队列投递，不再阻塞。
- 切换语言后缺陷列表、详情、历史等大块界面仍是旧语言：现在会立即刷新。
- 角色丢失或损坏的布局恢复后可能出现两个相同的「缺陷」标签：现在会收敛成一个。
- 窄面板下缺陷列表工具栏的「列 / 排序」按钮被裁掉：现在放不下时兜底换行。
