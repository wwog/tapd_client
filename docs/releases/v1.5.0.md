# TAPD Client v1.5.0

发布日期：2026-11-19

## 新增

- 工作流任务新增常驻「任务」页：任务信息、开始/提交/合并 hash，以及只有存在审核时才出现的摘要、改动文件与审核操作；任务入队后默认停在这里。
- 对话末尾新增任务完成卡：完成标记、分支、变更统计、三个 hash 与 TAPD 回写结果，点「查看任务」回到任务页。
- 本地事项行新增右键菜单：编辑事项、删除事项（删除前二次确认）；行内的 Agent 操作改成与缺陷列表一致的带文字描边按钮。

- Agent 标签栏右上角也有「打开」，打开当前会话的工作目录（worktree / 仓库 / 自由会话目录）；标签栏右端只显示当前聚焦标签的动作。

- 多轮对话的消息流左侧新增「提示词」入口：列出每轮提示词与这一轮的文件行数变化，点一条就跳回那一轮；只有一轮时不显示。

- 助手回复里的本地路径可以直接点开：Markdown 链接、行内代码里的文件名、以及本地图片，点击后都在右侧打开一个新的文件查看标签（相对路径按该会话的工作目录解析，项目里的文件仍落在对应项目标签下）；图片回复也能直接显示，http(s) 链接继续用默认浏览器打开。

- 左侧任务列表可以按项目折叠：点项目名收起该组，折叠状态记在本地，重启后保持。
- 任务行右键菜单：「在 Finder 中打开」打开该会话的工作目录（worktree / 仓库 / 自由会话目录），「删除会话」对所有会话统一可用。
- 项目页新增 Worktree 卡片：列出 Agent 建过、仍然占着目录的 worktree（包括已经没有会话的残留），显示默认目标目录并可直接打开，也可以就地删掉。
- 图片类工具行（`read_image`）展开后直接显示图片，不再显示 `<path>` / `<type>` 的文本包装；文件不在了或格式不支持时给一行原因。
- Agent「配置」新增「内置插件」：直接读运行时的 Loader，按「会话插件 / 全局插件」分组列出真正组成进来的插件（中文名、包名、说明、运行状态），支持搜索；本部署没有按会话组成的插件，那一组会说明原因。
- 外观设置新增「胶囊透明度」：0.6–1 之间拖动，默认 82%，改完立即生效（胶囊与通知卡共用 `--island-alpha`）。
- Agent 页可以随时停止当前回合（自由会话也有停止入口）：只中断这一轮，任务照常进入待审核 / 完成，不必再取消整个任务或退出应用。
- 配置页新增「重启运行时」：改完模型目录或同事名单后就地重启生效；有启动期配置改动时运行时区会显示提示。
- 输入框下方新增会话模式选择器：计划模式 / 变更前通知 / 自主 / 完全访问。计划模式接引擎原生 plan mode，先出计划，批准后再动手；模式切换只影响当前会话。
- 后台任务停在审批或提问时，左侧任务行显示琥珀色角标，点回该会话即可作答。
- `TestAgent` 增加 `/test agents`：派三个子 agent 各做一件事（文件查找、`curl` 本机接口、内容检索），用 `wait_agent` 收回，看子 agent 的任务轨迹与并发。
- 会话里可以直接切换模型：输入框下方显示「供应商/模型 · 思考强度」，点开先选供应商、再选该供应商的模型（上下文窗口 / 图像 / 推理，当前项打勾）；思考强度改成滑块，最左档「自动」表示不发送参数，可以在一级菜单里直接拖；切换只影响当前会话，重启后仍然保留。
- 供应商列表可以拖动排序：顺序就是优先级，第一个供应商的默认模型用于新会话；在任意供应商的模型行点圆圈「设为默认」会把它所在的供应商提到第一位。
- 对话区补上用量显示：每条消息下方有时间与复制，助手消息另有「用量 x tok」，点开看本轮提供方 / 模型、缓存命中率、未缓存输入、缓存读取与输出；输入框下方三个可点开的胶囊分别看会话统计（轮 / 步、模型用时、首 token 平均、输出速度）、Token 用量与上下文构成（已用比例、系统提示词 / 工具定义 / 对话消息）。
- 调试构建内置测试模型 `TestAgent`：本地 OpenAI 兼容端点，回复脚本化，一条就能跑完推理、正文、文件工具、命令、内置工具与提问卡片；用 `/test all|text|reasoning|files|tools|ask|error|long|ping` 切换脚本，文件只动工作目录下的 `tmp/test-agent/`；发布包不含该端点。
- 调试构建多一组 `/dev/ui/*` 接口：在应用自己的窗口里执行 JS、点按钮、读控制台、截 PNG（`node scripts/dev-probe.mjs eval|call|console|shot`），测界面不用再靠系统级截图与合成点击；发布包不注册。
- 助手回复按 Markdown 渲染：标题、列表、表格、行内代码与代码块都按排版显示，不再直接露出 `**`、`-` 原文。
- 模型设置改为「供应商 + 模型目录」：可以并存多个供应商（OpenAI 兼容、Responses、Anthropic、Gemini），每个供应商有自己的地址、协议与密钥。
- 每个模型可以单独设置上下文窗口、最大输出 Token、输入类型（文本 / 图片）与推理等级映射（等级 → 线上参数），全部渲染进运行时 profile；以前整份配置只能共享一个上下文长度。

## 修改

- 同一个事实只留一处：「任务」视图里项目与分支只在任务页显示，输入框不再重复；任务页的更新时间改用与会话活动一致的口径。
- 空值不再冒充内容：缺陷详情的创建人、版本、迭代等空字段整行隐藏，不再铺一排「—」；账户页不再用「已登录」当人名，并去掉与页面无关的装饰光斑；MCP 页去掉与真实状态无关的「已启用」徽标。
- 项目侧栏去掉与选中底色重复的绿点；点已选中的项目不再隐式打开文件浏览（hover 的文件夹按钮与右键菜单保留）。
- 同伴页的「如何贡献」整块说明收敛成页头一个按钮；捕获页的加载态与空态分开，加载时不再画成「没有结果」。
- 左侧任务列表收敛为单行：行首运行中转圈（被阻塞时是琥珀计数），只有工作流任务在标题前多一枚随状态变色的小标志；行尾 hover 出删除图标，hover 行弹出信息卡——基本信息（分支、模型、变更、消息、时间）加实时的工作目录列表，可下钻、文字可框选复制。
- 顶部「审核 / 对话」改为「任务 / 对话 / 轨迹」；审核内容并入任务页，任务完成后仍可回看。
- 收尾清理 worktree 后立即把会话 cwd 交回主仓库；完成后继续会话按直接轮次运行（无 worktree、无合并步骤，提交落在主仓库）。
- 本地事项状态跟着 Agent 任务实时刷新：入队即「处理中」，任务完成变「已完成」，取消或删除未完成任务恢复原状态；事项页不再需要切走再回来才更新。

- 会话计划（「任务 x/y」）从消息流顶部挪到「对话 / 轨迹」这一行右侧的浮动提示区：收起时是一枚小胶囊（当前任务或进度），不遮挡对话；点开时胶囊自身沿右上角长成面板（同一个壳、尺寸动画），看完整清单，右上角再「收起为胶囊」；长清单在卡内滚动。这块区域后续还会放正在运行的终端数与子 agent 数。
- 消息流与输入框两侧留白加宽；去掉顶部 tab 下沿和输入区上方的全宽横线。
- AI 会话区字号整体上调一档：任务列表、对话正文、轨迹与输入框都比应用基准大 1px，各档之间的层级不变；Agent 配置弹窗保持原来的字号。
- 对话区的轨迹分成层级：用时独立成行，不再和查阅 / 执行 / 修改混在一起 —— 运行中它是块底部的一行「工作中 N」，回合结束后变成块的头「已工作 N」。收起时只显示最新一项（正在思考 / 正在执行 …），展开后是 思考 / 说明 / 查阅 / 执行 / 修改 几个折叠组，再展开组才看到具体的工具行。
- 思考行默认折叠：折叠时一行「思考」+ 最新一句（过长 hover 滚动），流式中额外标「正在思考」；展开后与工具结果、图片共用同一个最大高度，内容在里面滚动。
- 工具行显示真正执行的命令（`bash` 不再显示模型给的描述），单行、放不下时 hover 滚动；点命令行直接切到轨迹并选中这次调用，结果仍在它下方折叠展开。
- 长文本（缺陷标题、任务名、文件名、项目名等）统一靠 hover 就地滚动看全：鼠标停留 0.5 秒后才开始匀速滚到末尾，移开立即归位；扫过列表时不会让一排标题同时滑动。
- 胶囊展开时按屏幕可用空间摆位置：水平方向仍以胶囊为中心，贴近左右边缘时整卡往里挪；垂直方向默认向下展开，下面放不下就翻到上方，两边都放不下时也保证整张卡留在屏内，关闭按钮不会再跑到屏幕外。
- 胶囊里的提问选项改成每个选项一行、固定占满卡宽：选项文案不再被挤成两行换行，放不下时 hover 按固定速度滚到末尾；选项说明（`description`）显示为第二行小字。审批这类短动作仍并排一行，文案过长同样改成 hover 滚动。
- 胶囊的提问卡最后多了「其他答案」输入框：可以直接回一句自定义内容（Enter 或右侧发送按钮），提交后键盘交还给原来在用的应用；胶囊平时依然不抢焦点。
- 权限模式改成会话级、即时生效：策略门每次工具调用都读当前模式，不再要求重启运行时；配置页的权限区变成「默认权限模式」，只影响新会话和没单独设置过的会话。
- 任务列表的状态点、时间和排序改读实时会话状态：以前只在回合结束刷新，聊天会话一直停在第一条消息、首轮的「运行中」点也可能常亮。
- 自由会话使用独立工作目录（`<data>/dsh/chats/<会话>`），运行时默认目录也改为中性的 `<data>/dsh/workspace`：不关联项目的会话不再借用第一个项目仓库。
- 工具动作行区分进行时：运行中的调用显示「正在执行 / 正在读取 …」，展开轨迹时同一个调用只出现一行，不再重复计数。
- 对话区按轮次组织：去掉轮与轮之间的分割线；每轮在提问下方先显示一行实时状态（正在思考的内容，或正在做的事：已执行命令 / 已读取 / 已写入 / 已编辑 + 行数增减），再显示「工作中 x 秒」或「已工作 x 秒」。点开这一行看整轮轨迹：查阅 / 执行 / 修改的计数、思考全文、逐条工具动作（失败的调用自动展开原因），正文只留最终回答。
- 运行时改成应用的一部分：随进程启动、随进程退出，一个进程服务所有会话；配置页与对话区不再有「启动 / 停止」，只有真失败时才给一个重试。
- 重启后用量不再是 0：打开会话时从 dsh 自己的日志补出历史，同时把该会话的轮数、token、缓存命中一起发布，胶囊直接显示真实数字。
- Agent「配置」页去掉底部保存按钮：模型、提示词、Worktree 与执行单元改完即存（输入停顿 0.5 秒落盘），权限模式仍是点击即生效。
- 「同事」从多选列表改成开关：打开即启用智能体团队、同事一起加入，关闭回到单干；具体是哪几位同事在「同事」页挑。
- Agent「配置」页的模型区改为左右两栏：左侧供应商列表带状态点（已配好 / 待补 / 停用），右侧是选中供应商的地址、协议、密钥与模型行；点模型行左侧圆圈设为默认模型。
- 新增 / 编辑模型改用弹窗，输入类型与推理等级收进「高级配置」。

## 修复

- 认领缺陷、评论、改处理人、状态流转成功后不再弹 toast：列表与详情已经重画，重复提示只是噪音（错误提示保留）。
- 本地事项的待处理 / 处理中 / 已完成页签不随任务进展更新：事项页只在挂载时读一次数据，任务入队、完成、取消都没有通知它；现在由 `local://items` 事件静默刷新并跟随当前可见事项切换页签。
- 删除失败或待审核的本地任务后，事项永远停在「处理中」并留下悬挂的任务 id：删除任务时会清掉链接并把事项恢复到 attach 前的状态。

- 任务完成后会话工作目录仍指向已删除的 worktree，继续会话无法进行；恢复会话/发消息时会重新指向 worktree 或主仓库。
- 完成后的回写提示词与实际不符（仍写「worktree 已清理」、模型复述「未修改代码」）：现在带上合并 hash 与工作区状态，并只要求报告评论与状态结果。

- 新会话「同事协作」明明关着，发第一条消息后又自己打开了：引擎在 Agent 创建时会先写入配置里的默认值（开），我们排队等 Agent 的「关」在同一个钩子里立即执行，读到的投影还没看到默认值，以为已经关着就跳过了写入，随后引擎记成开。现在排队的选择等引擎的创建钩子走完再应用，开关保持关闭；切换也改为即时反馈，新的自由会话不再有 3 秒不可点。
- 暗色主题下输入框有内容时发送按钮是一块白底白箭头：按钮用了固定的 `slate-900`，而暗色的 slate 是反色表。改用语义化的主按钮颜色，箭头在深浅两套主题里都清晰。
- 回合失败后任务被标成「已完成」，重试跑起来也不改回去：收尾逻辑只看工作区有没有改动，而失败回合根本没动过代码，于是判成完成；「完成」又是终态，后续回合回不到运行中。现在 `error` / `blocked` 回合记失败（不是完成），用户重新发消息或重试时才把任务重新打开。
- 「自主」模式下几乎每条命令都要审批：行里只要有 `>`（包括 `2>/dev/null`）就整行算写操作，然后把行内所有绝对路径都当写目标——`find`/`ls` 的操作数和 `/dev/null` 都算，所以读目录也要问。现在按命令段只取真正的写入目标（重定向文件、写命令的路径参数），设备文件不算写入。
- 选了「完全访问」还一直被拦：之前只关掉了我们自己的风险规则，引擎自己的沙箱（`workspace-write`）照样会为目录外的写入弹审批。现在权限模式同时决定引擎沙箱：自主保留 `workspace-write`（目录外的写只由引擎问一次，不再和我们的规则各问一遍），变更前通知与完全访问切到 `danger-full-access`，说放行就真的不弹。
- 自主模式下连自己的 worktree 都写不进去：引擎沙箱的边界取的是会话创建时的 header 目录，而任务和自由会话都是创建后才切到 worktree / 自己的目录，于是每次写入都被判「越界」，只能反复审批（或者直接被拒）。现在会话换目录时会把新目录注册成该会话的可写根（恢复会话时重新注册），worktree 内的写入不再需要授权。
- 失败回合点「重试」会把整段提示词再发一遍，模型上下文里同一条任务提示出现两次。现在走引擎自己的重试语义（空内容、`source.kind = retry` 的用户消息），只重跑这一轮，不再重复进上下文。
- 胶囊与卡片的底色有时看起来实、有时透：hover 会把底色从 0.82 提到 0.97，透明窗口里的 backdrop blur 又采不到任何东西、重绘时还可能整层丢失。现在去掉模糊和 hover 变化，胶囊始终是 0.82 的半透明底色，深浅主题各一套。
- 新会话还没发消息时切换模型界面不跟着变：那时会话还没有对话行，选择只写进了「不存在的行」。现在选择单独留一份，等后端报出这条会话的真实路由再撤掉。
- 回合失败（密钥错误、上游 500、被策略拦截）在对话区显示原因与「重试」，不再看起来像一次正常的「已工作 x 秒」；失败前的中途说明也不会再被当成最终回答。
- 运行时撤回提问（`user-question.cancelled`）后卡片会消失：以前主窗口会一直挂着，点提交只是对已取消请求回一个无效应答。
- 运行中杀掉 node 或重启应用后，不再出现一直增长的「工作中」计时器；从磁盘日志恢复的未闭合回合按空闲处理。
- 流式回复中途切走再回来不再截断或重复；提交后才迟到的增量会按已结算 `attemptId` 丢弃，不会把最终答案再渲染一遍。
- 上下文占用不再用会话累计 token 冒充（长会话会一直显示 100%）；运行时没上报时显示「待统计」。
- 不同会话的输入草稿互不串台。
- 会话记录的解压与解析不再占用异步线程和命令链路的等待时间。
- 上下文构成一直是「等待运行时的用量统计」：真正的根因是 payload 里 `@tapd/plugin-bridge` 还是旧副本（08:42 拷进去的），运行时根本没发过 `stats` 帧。现在 `pnpm check:dsh` 会把 `dsh/plugins` 的摘要和 payload 清单比对，插件改了没重打就直接失败；重新 `prepare:dsh` 后构成正常上报。
- 上下文构成不再随重启丢失：新增 `dsh_session_meters`（cache.sqlite3 schema v10），每个会话一行，`stats` 帧到达时异步写库，会话从日志补历史时回填，所以重启后也能看到系统提示词 / 工具定义 / 对话消息的占比。
- 输入框下方的状态行时有时无：没有会话行、上下文字段还没上报时整行会消失。现在选中会话就常驻，数字未知时显示 `—`，并随运行时的用量统计补齐。
- 重启后历史消息空白：运行时只有在会话被创建 / 恢复后才认识它，关闭再打开客户端时整段对话看起来全丢了。现在读 dsh 自己的会话日志（`session.v4.jsonl.zstd`，解压后走同一套归一化），运行时没启动也能显示历史；给恢复出来的会话发消息前会先 attach，不会被当成新会话。
- 左侧列表点一下就把行跳到最前：打开会话时会 resume 并顺手 `touch()`，把「最后活动时间」写成当前时间，列表又是按这个字段排序的。现在 resume 不再算作活动，重放历史里的 turn/end 也按事件本身的时间回填，列表按真实活动时间排序。
- 流式回复只显示最后一个增量：前端把每帧递增的 `revision` 当成「这一帧替换了整次尝试」，于是每来一个 delta 就把已有文本清空，整段回复要等落定才一次性出现。现在按 `attemptId` 判断新尝试（`revision` 回退才重置），文本按增量累积。
- 协议选项与运行时对不上：「Anthropic」「Gemini」写进 profile 的 `api` 不是 dsh 认的枚举值（应为 `anthropic-messages` / `google-generative-ai`），选这两项启动必然失败；旧配置读入时自动更正。
- 多供应商时密钥不再共用：每个供应商走各自的 `TAPD_DSH_API_KEY_<供应商>` 环境变量。
- 旧的单供应商配置读入后自动迁移成一个供应商，`agent.json` 不再写出 `dshModel` 字段。
