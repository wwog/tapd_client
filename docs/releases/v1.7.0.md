# TAPD Client v1.7.0

发布日期：2026-11-23

## 新增

- 回复还在进行时再发消息，会进入输入框上方的「待发送消息」队列（与 ZCode 一致）：这一轮结束后按顺序自动继续，不再直接插进对话。队列里的每一条都可以拖拽排序、编辑、移除；点「立即」（或 `⌘Enter`）会把这条插进正在跑的回复里，下一次工具调用后模型就能看到（等待期间气泡标注「等待引导当前回合…」），回合已结束则自动按普通消息发出；等待期间中途停止，这条会放回队列而不是丢失。队列存在本地数据库里，重启应用后仍在（重启后先暂停，点「继续」接着发）。
- 停止当前回复或本轮出错时队列自动暂停（内容保留），点「继续」恢复；队列还在时手动发送，会先问「清空队列」还是「保留队列」。
- 输入框的附件按钮改成「+」：图片和任意文件共用一个选择入口，图片作为附件随消息发送，其他文件插入 `@路径`；也支持把文件直接拖进输入框，按同样规则分流。
- 权限模式「仅通知」对每次文件改动都推通知卡（工作区内编辑、`sed -i`、git 写工作区等），不再只提示风险调用。

## 修改

- 模型设置的推理等级改成一行一个输入框：只填实际发给上游的取值，等级按顺序决定，「关闭」作为隐式下限不再占一行；不支持推理的模型不再传 `reasoningEffort`，避免上游报错。
- MCP 不再是左侧导航的独立标签，改为设置页里「Agent 配置」下方的一张卡片：服务状态、策略、调用审计与客户端导入都在同一个弹窗里。

## 修复

- 修复 macOS 上把文件拖进输入框或项目卡片时识别不到落点的问题（macOS 返回逻辑点，与其他平台的物理像素不同）。
