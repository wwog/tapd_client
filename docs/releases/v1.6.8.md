# TAPD Client v1.6.8

发布日期：2026-11-20

## 新增

- 输入框支持 `/` 指令面板：「添加」组是文件、目标、计划，「指令」组是压缩、权限、模型、下载日志；`↑`/`↓` 选择、`Enter` 执行，手动输入同样生效，未知指令仍按普通消息发出。
- 输入框空草稿按 `↑` 打开历史面板：本会话已发消息加上本地最近 50 条，选中后填入草稿而不直接发送。
- 对话区把指令结果显示成一条状态行（运行中 → 成功/失败），长期目标（`/goal`）显示在输入框下方的状态行里。
- 输入框支持发图片：选择或粘贴的图片随消息发送，用户气泡里显示缩略图，点击全屏预览。
- 输入框输入 `@` 弹出文件面板：按会话工作目录搜索文件（支持路径片段与模糊匹配），回车插入 `@路径`；插件、对话两类结果已预留。
- 对话尾部新增「变更卡片」：每一轮改动的文件默认收起显示数量与 +/−，展开逐个文件列出，点击打开文件。

## 修改

- 「同事」不再占据左侧导航：同事多选收进设置里的 Agent 配置，新增「同事」分组，原来的导航页一并移除。
