# TAPD Client v1.6.1

发布日期：2026-11-19

## 新增

- 引导页新增「配置 AI 模型」页（最后一页）：可以直接添加供应商、获取模型列表并添加模型，点「开始使用」时保存并自动启动运行时。

## 修改

- 模型页「获取模型」改为客户端直接请求供应商端点，不再依赖内置 Agent 运行时：运行时未启动、启动中或启动失败时也能拉到模型列表，不会再出现「内置 Agent 运行时未启动」。
- 保存模型后会自动拉起运行时，不需要再点「重试」；配置页的运行时卡片把未配置模型显示为「待配置模型」状态，而不是红色错误。
- 左侧活动栏移除「缺陷」入口，统一从项目列表进入缺陷与事项；栏位顺序改为 Agent、项目、工作流队列，其余不变。
- 项目页与功能页不再互斥：打开或切换到某个项目不会再关掉设置 / Agent / 队列等功能标签；功能页之间仍共用一个标签。
- 所有标签都可以关闭（包括功能页）；主区没有标签时显示欢迎页，列出 Agent、项目管理和终端入口，不再自动补一个缺陷页。
