# TAPD Client v1.6.7

发布日期：2026-11-20

## 新增

- 模型设置里的 API Key 支持显示与隐藏（输入框右侧眼睛按钮），切换供应商时自动收起。
- 项目侧栏的「本地项目」分组改为常驻：分组头悬停显示「+」（还没有本地项目时一直显示），不再需要从右键菜单进入新建。

## 修改

- 会话列表的收起与展开合并为对话区左上角同一个按钮，列表底部不再另设按钮。
- 欢迎页「打开终端」会先展开底部终端面板再新建 shell，面板处于收起状态时也能直接看到。
- 项目侧栏只在项目页点亮选中行：切到设置、Agent 等全局标签时，记住的项目不会再显示为选中。
- 内置 Agent 运行时升级到 dsh 0.2.2-rc.5。
