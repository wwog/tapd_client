# TAPD Client v1.7.2

发布日期：2026-11-24

## 新增

- 审核变更里的 diff 换成带新旧行号的视图：新增/删除行有底色和左缘色条，不必再自己数行；复制时保留 `+`/`-`，超长 diff 只渲染前 5000 行并提示剩余行数。

## 修改

- 对话页右上角的 todo 胶囊收起后只显示 `任务 1/4`：图标表示是否有任务在进行，全部完成时计数转绿，具体在做哪一条放回展开的面板里，胶囊宽度不再随任务标题变。

## 修复

- 回复流式输出时向上滚一点点就能停住：以前小幅上滚还在「到底部」的判定里，下一个字又把你拽回底部，只有一次大幅拖动才有效；现在任何向上的滚动都会立刻脱离跟尾，滚回底部或点底部的「跳到最新」再继续跟随。
- 展开或收起折叠时不再被拽回底部：跟尾会等折叠落定（约 0.4 秒）；折叠把底部推远就停在原处，没推远则继续跟随。
- 运行中「正在思考」的流程行不再悬停滑动，改回省略号，并显示这一行最新的内容（不再只显示句首、看起来像卡住）。
