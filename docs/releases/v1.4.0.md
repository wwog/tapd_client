# TAPD Client v1.4.0

发布日期：2026-11-16

## 新增

- 新增「对话」页：选择已配置本地仓库的 TAPD 项目与 Agent 后直接开启会话，会话在项目目录长驻，可在「对话 / 终端」之间切换；会话记录持久化，支持停止、继续会话与删除。
- 对话页模型选择支持自动发现：OpenCode 跑 `models`、Claude 走 `list_models`、Codex 走 app-server `model/list`、OMP 跑 `models --json`；读取失败时回退静态建议并提示。
- 对话页新建面板会记住每个运行时上次选择的模型（写入 `config.json` 的 UI 偏好），下次新建会话自动选中；显式选择「默认模型」同样会被记住。

## 修改

- 分割条与交叉点：高亮线改为 2px 圆角并贴合卡片间隙（不再越过卡片上下边缘），组间距 8px → 6px，交叉点手柄改为圆形；项目侧边栏去掉与统一分割条重叠的旧手柄，缩放提示改用完整文案。
- 「对话」页补齐中英双语：会话列表、新建面板、模型 / 权限选择、会话状态与后端会话 / 模型读取的错误提示全部进入中英文目录。

## 修复

- OpenCode 2 插件加载失败：`tapd-session-monitor.js` 同时支持 v1 具名导出与 v2 `default { id, setup }`；v2 用 `ctx.event.subscribe` 在后台订阅，事件字段兼容 `data` / `properties`，并在启动时自动修复旧版本写入的插件。
- OpenCode 并发权限不再「只能点一次」：插件按 PermissionID 跟踪未处理请求，只展示队首、回复后补发下一张；卡片不会再被同轮工具 / 文本事件清掉，只有真的被回答或回合结束才消失。
- 权限卡片新增「总是允许」：opencode 授权框能记住规则时（`permission.asked.always` 非空）才多出该按钮，按「右移 → 回车 → 二次确认回车」完成；不支持规则的请求仍只显示「允许一次 / 拒绝」。
