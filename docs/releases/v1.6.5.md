# TAPD Client v1.6.5

发布日期：2026-11-20

## 新增

- 手机端缺陷详情支持「转移处理人」：成员目录点选即转移（与桌面详情面板的处理人下拉对齐）。
- 手机端缺陷详情与本地事项支持「交给 Agent」：可附补充说明、选择模型，任务进入与桌面相同的队列。
- 手机端 Agent 页新增「任务 / 队列」切换；队列按执行中、已中断、排队中、待审核、收尾中分组，可继续中断的任务或取消排队/执行中的任务。
- 手机端任务列表支持删除会话（与桌面相同的二次确认；worktree 与本地事项状态一并处理）。
- 手机端审核文件可就地展开 diff，也可跳内置查看器打开原文件；失败回合支持一键重试。
- 手机端任务页新增「打开缺陷 / 打开事项」跳转与模型信息。

## 修复

- 手机端同一链接频繁出现「配对码无效」且无法再进入：会话 token 迁到 localStorage（关闭标签页 / 系统回收后直接恢复会话），配对码改为运行期门钥匙（配对成功不再作废、重新出码时复用现有码），链接在应用运行期间始终能重新配对。
- 手机端队列视图不再把自由会话（chat）当作工作流任务渲染；此前每个会话都出现在「执行中」分组并带取消按钮，点下会把聊天记录永久置为已取消。
- 排队中的工作流任务不再接受对话（此前模型会在调度器之外运行，成果永远进不了审核/合并链）；队列里排队中的行点开直达来源缺陷/事项。
- 限速改为按设备计数（隧道下所有手机共享 127.0.0.1 一个来源 IP，按 IP 计数会互相挤爆预算）；请求缓存修复写操作后旧响应回填覆盖新值的问题（评论/流转后最长 60 秒看不到自己的写入）。
- 引导页最后一页的模型卡片无法打开「添加/编辑模型」弹窗（弹窗层级低于引导层）。
- 项目列表不再因为只有一个项目而自动隐藏；收起后可以随时点标签栏左侧的按钮展开。

## 修改

- 手机端事项并入缺陷页，顶部「缺陷 / 事项」切换，底栏移除独立事项入口；事项分组对齐桌面为「待处理 / 已完成」两段（进行中的事项留在待处理，执行中工作统一看 Agent 队列）。
- 手机端整体打磨成 iOS 质感：毛玻璃半透明标签栏、底部 sheet 增加拉手、去掉点按灰色高亮；统一页面左右边距（16px 盒缘）、列表行高、sheet 按钮触控高度（44px）、空态高度与页头节奏，修正缺陷详情/设置页三种左边缘并存、输入框与对话区不对齐等问题。
- Agent 配置入口移到设置页顶部，改成与「运行信息」同款的卡片（位于外观之上）；任务列表底部不再保留配置入口。
- 模型编辑的「输入类型」移到主表单；新增或获取的模型默认勾选图片，仍可手动取消。
