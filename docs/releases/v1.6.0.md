# TAPD Client v1.6.0

发布日期：2026-11-19

## 新增

- 会话列表可以拖动改宽（200–360，双击复位）、可以收起；窗口太窄时自动收起，只在对话左上留一个展开按钮。宽度与收起状态会记住。
- 后台服务启动失败时弹出一个对话框：伴侣服务与内置 Agent 运行时各自动重试 3 次后仍失败，可以查看日志、单独重试或重启应用。
- 左侧活动栏新增「工作流队列」：跨项目列出执行中、排队中、已中断、待审核与收尾中的任务，显示标题、项目、创建时间、状态、模型、分支、改动和排队序号，可继续、取消；有会话的任务可打开。
- 工作流队列新增完成报告与角标：队列有任务时导航图标为黄色；队列中的任务都结束（完成/取消/失败）后变绿色，已中断任务不算进行中；进入队列可看到「上次队列完成」报告（完成/取消/失败及逐条结果）。
- 本地事项新增详情面板（与缺陷详情同位置的侧栏）：状态、重要度、创建/更新时间、描述、关联 Agent 任务，以及编辑、流转、删除和交给 Agent。
- 新增/编辑事项支持重要度（低/中/高），事项列表与详情都会显示；列表行显示创建时间。
- 工作流队列的行和完成报告可点击跳转到缺陷详情或本地事项详情。

## 修改

- 缺陷与本地事项的队列视图合并：缺陷列表的「队列中」页签、本地项目的「处理中」页签移除，执行中的任务统一只在工作流队列里查看。
- 本地事项列表行内的「移入处理中 / 完成」按钮移到右键菜单；「交给 Agent」保留在行内。
- 已交给 Agent 且仍在执行 / 排队的缺陷不再重复出现在「我负责的 / 全部」里，统一只在工作流队列中查看；待审核、收尾中的缺陷仍留在原列表。
- 本地事项列表只保留「待处理 / 已完成」两个分组；处理中的事项留在待处理分组并带状态标记，不再有单独的「处理中」页签。
- 「交给 Agent」后停留在当前页面，不再自动跳转到 Agent 任务；排队中的任务还没有会话，队列里只提供来源详情与取消，不提供「打开任务」。
- 本地数据库自动升级到 v3：已有事项补上默认重要度「中」，旧数据与项目规则保持不变。
- 运行中的会话行末尾不再显示每秒跳动的相对时间，改成「忙得飞起」；其它行照常显示时间。
- 任务页与轨迹页不再显示输入框，两个只读页面占满高度；切回对话时草稿还在。
- 任务页底部右侧的更新时间已移除。
- 标题里 TAPD 的全角标点统一转成英文标点，会话标题、任务行、悬停卡与伴侣端都走同一套转换；复制与导出仍保留原文。

## 修复

- 缺陷 / 事项的「交给 Agent」卡片里点开模型菜单，选模型不会再整张卡片关闭；卡片内滚动、右键备注也不会被当成外部操作。
- 「重启应用」会先停掉 Agent 运行时、终端与伴侣隧道，再重启进程。
- 运行时初始化失败（响应格式不符）时会先停掉子进程，不再被下一次启动误判为已运行。
- 伴侣服务在自动重试期间被关掉后，不会再被重试重新拉起来。
- 手动停止一轮或应用中途退出后，任务不再一直显示「进行中」：状态改为「已中断」，任务页提供「继续」，工作流队列里也能直接继续。
- 任务行、悬停卡与任务页显示的颜色/文案跟随真实的已中断状态，不再把已停止的任务画成运行中。
- 通知卡片的高度改为界面实测回填：字号调大后标题不再被裁、按钮不再压住内容，内容过长时卡内可以滚动。
